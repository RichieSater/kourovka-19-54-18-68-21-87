## Necessary changes

### ER7-01 — state the problem precisely

The introduction's phrase “indices have no common divisor” is literally
false because every integer is divisible by \(1\), and “\(d\)-generated” can
be misread as “generated by exactly \(d\) elements.”  State instead that
\(G\) has a nonempty family of subgroups, each generated by at most \(d\)
elements, whose indices have greatest common divisor \(1\), and ask whether
\(d(G)\leq d+1\).

### ER7-02 — name the fiber map

Define the coordinatewise quotient map

\[
  \rho:L^d\longrightarrow (L/A)^d
\]

before introducing its common fiber \(\Omega\).  State that the tuples
\(\mathbf h_j\) have the same image under \(\rho\), that
\(|\Omega|=|A|^d\), and that \(\Gamma_{L,A}\) acts componentwise on
\(\Omega\).

### ER7-03 — distinguish generic coordinates from the generators

The symbols \(h_i\) already denote the chosen generators.  For a generic
element \(h\in H\), write \(h=(x_1,\ldots,x_k)\), deduce
\(x_s=\alpha(x_r)\), and continue with \(x_r,x_s\) throughout the
supported-coordinate contradiction.

### ER7-04 — name the coordinate image of \(H\)

After defining \(T_j\), put

\[
  H_j=\langle h_{1j},\ldots,h_{dj}\rangle.
\]

Identify \(H_j\) as the image of \(H\) under the \(j\)-th coordinate
projection.  State that the tuple stabilizer fixes \(H_j\) pointwise and
that \(T_j\leq H_j\) because \(T\leq H\).
