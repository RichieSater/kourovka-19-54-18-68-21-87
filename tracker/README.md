# Tracker data

`portfolio.json` is the machine-readable milestone record. `../TRACKER.md` is
the human dashboard. Both must change in the same commit.

Milestone order is fixed:

1. initial solution;
2. revision 1 and referee pass 1;
3. revision 2 and referee pass 2;
4. revision 3 and referee pass 3;
5. revision 4 and referee pass 4.

The `complete_legacy` state means equivalent historical evidence was mapped
after the fact. It does not imply external peer review or exact conformance to
the new artifact naming convention.
