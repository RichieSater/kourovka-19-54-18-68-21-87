# Shared infrastructure

This directory is for assets that are genuinely independent of the three
mathematical predicates.

Acceptable shared material includes:

- software/environment locks;
- simple-group inventory identifiers;
- logging and certificate metadata schemas;
- checksum utilities;
- source and exception manifest schemas.

Problem-specific property functions, inheritance lemmas, witnesses, and
verdicts stay inside their problem directories. There is no shared executable
mathematical code yet.
